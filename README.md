# City Explorer

Mini-site de prezentare a unor destinații turistice, realizat în cadrul disciplinei Tehnologii Web. Pagina conține o selecție de orașe europene cu detalii de călătorie, un formular static pentru planificarea unei vacanțe și o secțiune dedicată sfaturilor practice[cite: 6]. Interfața este realizată cu HTML5 semantic și stilizată adaptiv folosind CSS Flexbox și Grid[cite: 1, 4, 6].
